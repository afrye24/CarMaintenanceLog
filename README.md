# 🚗 Car Maintenance Tool

## :star2: About the Project
The **Car Maintenance Tool** is an application designed to help vehicle owners receive recommendations for routine maintenance, like oil changes or tire rotations, based on mileage.

⚠️ **Note:** As of 8/19/2025, the tool is customized specifically for the 2008 Scion xB for personal use.  
It does not support multiple car makes, models, or years, but could be expanded upon in the future.

It aims to:  
- Prevent overdue services  
- Extend vehicle lifespan through routine maintenance
- Provide quick and easy access to maintenance schedules

- 🔧 Receive **automated maintenance recommendations** based on the input
